🌐 Hướng Dẫn Antidetect Browser (Gologin, AdsPower, Hidemyacc)
1. Thông tin điền vào profile trình duyệt:

- Loại Proxy: Chọn HTTP hoặc SOCKS5 (server tự động nhận diện).
- IP / Host: 103.199.11.9
- Port: Cổng bạn đã gán cho profile đó (VD: 10010).
- User / Password: Tài khoản xác thực của cổng đó.

2. Cơ Chế 50 Luồng Dùng Chung 1 Cổng (Session-based Sticky):

Bạn không nhất thiết phải tạo 50 cổng khác nhau! Chỉ cần mở 1 cổng duy nhất với chế độ Sticky X giây, sau đó các luồng client truyền username kèm tag luồng:

Luồng 1: user-session-1  |  Luồng 2: user-session-2  |  Luồng 50: user-session-50

Mỗi luồng sẽ tự động nhận 1 IPv6 riêng biệt, giữ nguyên trong thời gian đã cài (VD: 10s/30s) mà hoàn toàn không bị đụng độ nhau!

3. Lệnh cURL Kiểm Tra Nhanh:
curl -x http://user:pass@103.199.11.9:10010 https://api64.ipify.org?format=json
💻 Code Mẫu Python Requests Đa Luồng
import requests # 50 luồng dùng chung 1 cổng mà mỗi luồng nhận 1 IPv6 xoay độc lập: session_id = "thread_1" proxy_user = f"user-session-{session_id}" proxy_pass = "mypassword" server_ip = "103.199.11.9" port = 10010 proxies = { "http": f"http://{proxy_user}:{proxy_pass}@{server_ip}:{port}", "https": f"http://{proxy_user}:{proxy_pass}@{server_ip}:{port}", } response = requests.get("https://api64.ipify.org?format=json", proxies=proxies, timeout=10) print("IPv6 của luồng:", response.json()["ip"])
